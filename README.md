# Praku Study

Praku Study is a free educational platform for students.

Access free educational batches, courses and learning resources
from different educational platforms in one place.

Praku Study provides free study batches for Class 6, Class 7,
Class 8, Class 9, Class 10, Class 11 and Class 12 students.

Download the Praku Study Android app and explore educational
courses and batches.
